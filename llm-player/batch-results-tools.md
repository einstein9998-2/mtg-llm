# With-tools batch: Alurentell (me) vs UR Cutter (Forge AI), same seeds as the no-tools batch

Setup: same decks, engine and serializer as [batch-results.md](/mnt/project-files/llm-player/batch-results.md). Every pick goes through `sh /mnt/project-files/llm-tools/bin/tplay` (folds each prompt into the view); tools used when they might help: `get_card`, `library_odds`, `sample_opp_hands`, `notes_read`. Run folders are `runs/tNN` (NN = the no-tools game with the same seed, so t07 = seed 208 = a07). Seats follow the die roll for that seed; I pick play first when offered. Blunders judged after each game with full information (`review.py`), same method as before. The helper scripts (`pass_safe.py`, `loop.py`) still call `play.py` directly, so the view goes stale during those stretches until the next full-state prompt.

## Summary

Final: 20 games, seeds 208 to 227 (same seeds as no-tools games a07 to a26). **With tools 18-2 (90%, Wilson 95% interval 70 to 97%)**. No-tools batch on the same seeds, a07 to a26: 17-3 (85%, 64 to 95%). The intervals overlap almost entirely, so this is not evidence that tools help.

**Confound, stated up front:** the tools batch was played after the no-tools batch, so it benefits from the 40-game playbook (`alurentell-playbook.md`: Veil first, wait for a spare mana against Daze, avoid nonbasics into Wasteland, one pick per command). Games with the same seed also diverge from the first different decision, so paired comparison is loose.

- Seats: 10 on the play (9-1), 10 on the draw (9-1). The first six tools games were on the play where the no-tools game was on the draw (t11 to t15), the rest mirror the a-batch.
- Paired by seed: both won 16, both lost 1 (seed 211: t10 and a10), tools won where no-tools lost 2 (seeds 209, 213: a08, a12), tools lost where no-tools won 1 (seed 219: t18). Three discordant pairs out of 20 says nothing either way.
- Tool use: 7 tool calls in 20 games (`library_odds` x5, `get_card` x1, `sample_opp_hands` x1); the other 15 games used none. None changed a decision that decided a game; the one that came closest was the Daze estimate in t19. Most prompts are not helped by a tool: the decisions are about sequencing and mana, which the menu already shows, and what the opponent holds is not computable beyond a prior.
- Costly blunders (judged by hindsight): 1 moderate process error (t07: chained `get_card` and a pick, so I activated Boseiju before reading the card text) and 1 costly one (t18: chained passes skipped my land drop, lost). Several no-cost slips (stale menu index, stray passes; t26 had two, both landed in main 2 so nothing was lost). All came from chaining or reusing an old menu number, not from misjudging a position.
- Losses: t10 (Show and Tell met Force of Will, flood; same as a10) and t18 (own blunder, then Daze on a no-spare Aluren at low life).
- What actually decided games: the opponent's counters versus my spare mana and Veil timing, mulligans, and whether Brainstorm or Stock Up found Aluren, Show and Tell or Atraxa. When the opponent taps out on its own turn it stays tapped on mine, and that was the window in t22, t23, t25 and t26.
- Turns per game (tools): median 8; the fastest were t24 (5, Show and Tell for Omniscience on my third turn) and t13 (5).
